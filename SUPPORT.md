# Getting Support

Orchid Ranker is a small, maintained open-source library. The primary support
channel is the [GitHub issue tracker](https://github.com/mlgorithm/orchid-ranker/issues).

Before opening an issue, check the [README](README.md), the
[documentation](https://mlgorithm.github.io/orchid-ranker/), and existing
issues. For an installation or usage question, include the Orchid Ranker and
Python versions, operating system, a minimal example, and the full error
message with sensitive data removed.

Use the bug-report form for reproducible defects and the documentation form
for unclear, incomplete, or incorrect docs. Feature proposals are welcome as
issues, but should explain how they reinforce the single `AdaptiveRanker`
workflow described in [CONTRIBUTING.md](CONTRIBUTING.md). Opening an issue
before investing in a large pull request helps keep work in scope.

The project has no guaranteed support response time or private product-support
channel. Please do not post credentials, learner records, access tokens, or
other confidential material in an issue. For a suspected vulnerability, follow
[SECURITY.md](SECURITY.md) instead.
